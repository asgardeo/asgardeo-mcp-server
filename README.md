# Asgardeo MCP Server

This repository contains two MCP servers for Asgardeo and WSO2 Identity Server, which let you use LLM tools to work with your organization in natural language.

> [!IMPORTANT]
> **Experimental Feature Notice**  
> This software includes experimental functionality and is not intended for use in production environments.
> Features, APIs, and functionality may change as the implementation evolves without prior notice.

| MCP Server | For | What it does |
|---|---|---|
| [Asgardeo MCP Server](docs/asgardeo-mcp.md) | Administrators and developers | Manages your organization with an M2M application: applications, login flows, API resources, users and claims. |
| [Self Service MCP Server](docs/self-service-mcp.md) | End users | Manages the signed-in user's own account with their access token: profile, sessions, sign-in security, linked accounts, apps and consents. |

See each server's guide for setup, configuration, available tools and example prompts.
